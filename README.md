# Buscando a Paquito

Un juego de rojos y fachas para jugar con el móvil (5 a 15 votantes).

- Web: React + Vite, publicada con GitHub Pages (`.github/workflows/deploy.yml`).
- Datos y reglas: Supabase. Todo el motor del juego está en `supabase/schema.sql`.
- Configuración pública en `.env.production` (URL y clave *anon* de Supabase, que son públicas por diseño).
